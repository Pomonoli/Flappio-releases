# Flappio for Android TV

Flappio is an Android TV and Android app based on [AIOStreams](https://github.com/Viren070/AIOStreams), with its native player, subtitle tools and profiles.

The first signed release is being prepared. No production APK is available here yet.

This repository will distribute versioned APKs, the stable update feed and matching source archives under AGPL-3.0. Signing keys, account settings and server credentials are not part of the downloads.

Flappio uses a separate Android application ID and can be installed alongside the official AIOStreams app. Future Flappio releases use the same signing certificate so updates retain Flappio's settings and sign-in.
